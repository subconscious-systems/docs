Choose the format with the response selector above. The default is OpenRouter Provider V2, and `?format=models.dev` returns a models.dev provider document.

- [Download the OpenRouter Provider V2 schema](https://openrouter.ai/docs/assets/provider-monitor-schema-v2.openapi.json) for the default format.
- <a href="/schemas/models-dev.schema.json" download="models-dev.schema.json">Download JSON schema</a> for the `?format=models.dev` document.
  - *Note*: We add a `metadata` field to each model. Make sure your handler is robust to extra fields.
