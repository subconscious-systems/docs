Machine-readable **429** / **403** bodies and headers for `POST /v1/chat/completions`, `/v1/messages`, and `/v1/responses`. The same components are merged into [openapi.json](/api-reference/openapi.json) on those operations — use the endpoint pages when previewing locally with `mint dev`.

<Note>
`mint dev` does not serve raw files under `/schemas/` (same as [catalog.schema.json](/schemas/catalog.schema.json) on List models). Download works on the **deployed** docs site only.
</Note>

## Download

- **Deployed:** [inference-throttle.openapi.json](https://docs.subconscious.dev/schemas/inference-throttle.openapi.json) (available after this docs release is published)
- **In repo:** `schemas/inference-throttle.openapi.json`

## Components

| Name | Use |
|------|-----|
| `InferenceThrottledOpenAI` | Chat Completions, Responses — **429** |
| `InferenceThrottledAnthropic` | Messages — **429** (JSON body without `retry_after_seconds`; use `Retry-After`) |
| `EntitlementSuspendedOpenAI` / `EntitlementSuspendedAnthropic` | **403**, no `Retry-After` |

Narrative: [Rate limits and Retry-After](/features/rate-limits-and-retries).
